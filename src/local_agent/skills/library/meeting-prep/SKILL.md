---
name: meeting-prep
description: >-
  A one-page brief before a meeting: who's coming, what it's about, open threads, what to decide. Use for "prep me for my next meeting", "brief me on the 3pm".
requires: [GOOGLECALENDAR|OUTLOOK]
---
1. Find the meeting (next one if not named): title, time, attendees, description, attached docs.
2. For each attendee: search memory first. If the agent has email, find the last thread with them (subject and one line). Search the web only for external people the user doesn't know, and only their role and company.
3. Read linked or attached docs if a tool can open them; summarize each in 2 lines.

Write it as:
- **What**: purpose in one line, time and length.
- **Who**: one line per person, `Dana Cohen, design lead at Acme, last talked about the July launch`.
- **Open threads**: unresolved questions from recent emails or notes.
- **To decide / to ask**: 2 to 4 bullets.

Rules:
- Under a page. Say what you couldn't find instead of guessing.
- Don't email or message attendees.
- If something durable came up (a new person, a decision), offer to save it to memory.
